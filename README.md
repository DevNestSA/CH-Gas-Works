# CH Gas Works

Professional website for CH Gas Works, a South African gas installation and maintenance company.

## Stack

- Vite
- React
- React Router
- Hand-written CSS (no UI kit)

## Local development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Where to edit content

- Business details and placeholders: `src/data/site.ts`
- Service list: `src/data/services.ts`
- Shared layout: `src/components/`
- Pages: `src/pages/`

Replace `[CH GAS WORKS LOGO]` in `src/components/Logo.tsx` with the real logo image when it is available. Replace `/public/hero-placeholder.svg` with photography.

## Placeholders

Do not publish invented phone numbers, addresses, credentials or testimonials. Keep square-bracket placeholders until the client confirms the real details.
