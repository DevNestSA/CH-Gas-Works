## 🔥 About

**CH Gas Works** is a professional business website created for a South African gas installation and maintenance company.

The website was designed to give CH Gas Works a strong online presence while making it easy for potential customers to understand the company's services and get in contact.

With gas industry experience dating back to **1999** and the business established in **2012**, the website communicates a focus on professional workmanship, practical solutions and dependable service.

---

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/DevNestSA/CH-Gas-Works.git
cd CH-Gas-Works
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

The development server will provide a local URL where the website can be viewed.

---

## 🔐 Environment Variables

The contact form uses **EmailJS**.

Create a local `.env` file in the project root:

```env
VITE_EMAILJS_PUBLIC_KEY=your_public_key
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_TEMPLATE_ID=your_template_id
```

> ⚠️ **Never commit your `.env` file or private credentials to GitHub.**

Recommended `.gitignore`:

```gitignore
node_modules/
dist/
.env
.env.local
.env.*.local
.vercel/
.DS_Store
Thumbs.db
```
